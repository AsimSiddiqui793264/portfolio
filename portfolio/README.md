# Asim Siddiqui — React Portfolio

A responsive, single-page portfolio built with React and Vite.

## Run locally

```bash
npm run dev
```

Create a production build with `npm run build`. Run `npm run lint` to check the source.

## Personalize before publishing

- Update the introduction, location, and about copy in the matching component in `src/components/`.
- Update project titles, previews, links, technologies, and descriptions in `src/components/ProjectsSection.jsx`.
- Update the example experience and education entries with your real history.
- In `src/components/ContactSection.jsx`, replace `your.email@example.com` with your email and set `whatsappNumber` to your international phone number without `+` or spaces.
- The contact form opens a prefilled email draft; the visitor must send it from their email app. Direct form-to-inbox delivery needs an email provider or backend.
- Update the LinkedIn/GitHub links in the Contact section.
- Update the page title and description in `index.html`.
